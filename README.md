# 牛马助手（燃脂版）· Niuma

一个 Windows 桌面悬浮窗小工具：实时显示你今天“已经燃烧”了多少卡路里，数字平滑滚动，精确到小数点后 5 位。

设定一段固定时段和一个额度，程序把额度按时段均分，一秒一秒往上累计；中间可以扣掉休息时段，也可以给某一段加倍数。看起来就是个记录消耗的小玩意儿。

## 功能

- **实时累计**：按时段与额度逐秒平滑递增，无跳变
- **状态显示**：休息日 / 未开始 / 燃烧中 / 休息中 / 加练中 / 已结束，附结束倒计时
- **今日进度条**、当前速度（每秒 / 每分钟）、每小时与每分钟均值、本月累计、距结算日天数
- **兑换清单**：「再过一会儿，一份沙拉就烧掉了」，可自定义条目和数值
- **励志语录**：每 10 分钟轮换一条，可自定义
- **原生悬浮窗**：可置顶、拖动、贴边吸附、托盘图标
- **迷你模式**：双击窗口切换
- **隐藏数值**：一键把数字显示为 `****`
- **鼠标穿透**：窗口不挡点击
- **自适应分辨率**：窗口高度约占屏幕一半，1080p / 2K / 4K、任意系统缩放、多显示器都按当前屏幕自动适配
- **可自定义**：软件名称、背景图片（可选，默认不带图，纯色渐变底）、透明度、界面大小、小数位数、数值单位、记录日、休息时段、加练倍率、结算日、开机自启、起止提醒
- **单日调整**：右键菜单可把今天标记为休息或照常记录

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Alt + M` | 显示 / 隐藏窗口 |
| `Ctrl + Alt + H` | 隐藏 / 显示数值 |
| `Ctrl + Alt + T` | 开关鼠标穿透 |
| 双击窗口 | 切换迷你模式 |
| 右键窗口 | 打开菜单 |

## 下载使用

到 [Releases](../../releases) 页面下载 `niuma-calorie-v1.0.0.exe`（就是本程序，运行后窗口里显示为「燃脂助手」），双击即可，无需安装。

系统要求：Windows 10 / 11（自带 .NET Framework 4.8）。

## 从源码编译

不需要安装 Visual Studio，系统自带的 .NET Framework 编译器就够了。在项目目录打开 PowerShell，运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

编译完成后，项目目录下会生成 `燃脂助手.exe`。只有 `src\app.ico` 会被打包进 exe，程序不带任何内置背景图。

## 项目结构

```
├── build.ps1              编译脚本
├── tools
│   └── make_icon.py       生成 app.ico（Pillow，火焰图标）
└── src
    ├── App.cs             程序入口、单实例、通用 UI 工具
    ├── Engine.cs          额度与时段计算、兑换提示
    ├── MainWindow.cs      悬浮窗主界面、托盘、快捷键
    ├── Odometer.cs        滚轮翻牌数字控件
    ├── Settings.cs        设置项的读写（含默认文案）
    ├── SettingsWindow.cs  设置窗口
    ├── app.ico            图标
    └── app.manifest       DPI 感知声明
```

## 设置文件

设置保存在 `%APPDATA%\NiuMaTuoMinQi\settings.ini`（目录名沿用自上游，升级后配置不会丢）。删除这个文件即可恢复默认设置。
